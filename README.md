A one-line office joke about the mute button — the universal remote-work mishap, with a twist: the silence was the contribution. "I pitched my big idea for ten straight minutes on mute, and my boss still called it my most productive contribution of the quarter." The program writes that single line (131 characters) to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
